# Windows-InstallDate-InstallTime-Change


## Windows InstallDate/InstallTime Change  
Automatically set the installed date/time of Windows for you as today (at this moment).  
This program can be used for life and does not need to be updated.  
(Based on the development of Windows 11 24H2, Windows 10 may be available)

本程序可终身使用，不需要更新。
